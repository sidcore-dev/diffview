# Contributing

Thanks for considering a contribution — this project is MIT licensed, so bug
reports, fixes, and small features are welcome.

## Setup

This is a static, client-side tool with no build step and no dependencies.

```bash
git clone https://github.com/sidcore-dev/diffview.git
cd diffview
open index.html
```

Any modern browser can open `index.html` directly — there's nothing to
install or compile.

## Making a change

1. Fork the repo and create a branch off `main`.
2. Test your change by opening `index.html` and exercising it manually
   (there's no automated test suite, given the project's size).
3. Open a PR describing what changed and why.

## Reporting a bug

Open an issue describing what you did, what you expected, and what
happened instead. Screenshots help for anything visual.
